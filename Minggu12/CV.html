Halo! nama saya Meila Syafa Az Zahro. Saya adalah mahasiswi aktif Program Studi Sistem Informasi di Fakultas Ilmu Komputer. Saya memiliki ketertarikan yang besar dalam bidang UI/UX Design. Saya senang belajar hal baru terutama dalam hal teknologi informasi. Selain itu,, saya juga tertarik untuk mengembangkan kemampuan dalam pemrograman dan pembuatan sistem yang mudah digunakan. Halaman web ini di buat menggunakan HTML murni tanpa menggunakan CSS untuk memenuhi instruksi oembuatan struktur dasar web. Dalam pembuatan halaman ini, saya menggunakan berbagai tag HTML untuk menyusun struktur dan menampilkan informasi. Saya juga mempelajari fungsi dari setiap tag agar dapat digunakan sesuai dengan kebutuhan halaman web. Pembuatan halaman ini menjadi salah satu latihan untuk memahami dasar-dasar pengembanga web. Dengan latihan ini, saya berharap dapat memahami HTML dengan lebih baik dan mampu menggunakannya dalam membuat halaman web yang lebih kompleks.
